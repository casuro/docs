## A360 Assessment Workflow

### Create assessment

Login to casuro.ai and click on assessments on the left menu bar. 
Choose the assessment you want to use (in this case it is A360). 
Click on the "New" button and select "From Job Posting". 
Optionally, you can also create an assessment from a blank template.

<Frame>
  <img 
    src="/images/integrations/lever/workflow/a360-1.png" 
    alt="Descriptive alt text" 
  />
</Frame>

Select the job posting you want to create an assessment from and click on "Create".

<Frame>
  <img 
    src="/images/integrations/lever/workflow/a360-2.png" 
    alt="Descriptive alt text" 
  />
</Frame>

Once the assessment is created and you are satisfied with the assessment, you can click on "Launch".

<Frame>
  <img 
    src="/images/integrations/lever/workflow/a360-3.png" 
    alt="Descriptive alt text" 
  />
</Frame>

Congratulations! You have successfully created an assessment.

### Setup triggers (automation)

Go to the launch page by clicking on "Go to launchpad" button.

<Frame>
  <img 
    src="/images/integrations/lever/workflow/a360-4.png" 
    alt="Descriptive alt text" 
  />
</Frame>

Scroll to the bottom and click on "Automation" tab. Click on the trigger stage you want to use for this assessment. Then, click on copy button to copy the assessment tag.

<Frame>
  <img 
    src="/images/integrations/lever/workflow/a360-5.png" 
    alt="Descriptive alt text" 
  />
</Frame>

<Note>
**Optional but recommended**: Create assessment specific stages as shown in image below. To create custom pipeline stages, please follow this [guide](https://help.lever.co/hc/en-us/articles/20087324594333-Modifying-pipeline-stages). 
</Note>

<Frame>
  <img 
    src="/images/integrations/lever/workflow/a360-6.png" 
    alt="Descriptive alt text" 
  />
</Frame>

On Lever, go to the job posting you want to use this assessment for and add the tag copied from casuro.ai in the "Tags" section.

<Frame>
  <img 
    src="/images/integrations/lever/workflow/a360-7.png" 
    alt="Descriptive alt text" 
  />
</Frame>

That's it! You have successfully set up the trigger for this assessment.
