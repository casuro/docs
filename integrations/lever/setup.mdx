## Testing the integration

<Frame>
  <img 
    src="/images/integrations/lever/setup/test1.png" 
    alt="Descriptive alt text" 
  />
</Frame>

You can test the integration by clicking on “Test” in casuro.ai settings page under ATS integrations tab. 
This will test casuro.ai to Lever requests.

<Frame>
  <img 
    src="/images/integrations/lever/setup/test2.png" 
    alt="Descriptive alt text" 
  />
</Frame>

You can also test the webhook integration from Lever by clicking on “Verify webhook” in the Lever webhooks page. 
This will test Lever to casuro.ai requests via webhooks.

## Debugging

If you face any issues, you can check the logs in casuro.ai settings page under ATS integrations tab. 
This will show you the logs of the integration.
