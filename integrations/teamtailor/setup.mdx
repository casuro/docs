## Step by step guide

Follow these simple steps to get started with Teamtailor integration with casuro.ai

{/* Steps */}


1. Open casuro.ai and click on settings on the left menubar.

/images/integrations/teamtailor/setup/step-1.png

2. Under ATS integrations, click on connect to Teamtailor to connect.

/images/integrations/teamtailor/setup/step-2.png

3. You will be presented with a form to input integration key and teamtailor API key.

/images/integrations/teamtailor/setup/step-3.png

4. Now go to teamtailor marketplace and search for casuro.ai integration. Make sure it is enabled.

/images/integrations/teamtailor/setup/step-4.png

5. Click on the integration and then click on "Go to settings" button.

/images/integrations/teamtailor/setup/step-5.png

6. Copy the integration key from teamtailor and paste it in casuro.ai.
/images/integrations/teamtailor/setup/step-6.png

7. Now go to left sidebar of teamtailor to search for "API". Create a new API key with Admin read/write access. Copy it.
/images/integrations/teamtailor/setup/step-7.png

8. Paste the API key in casuro.ai and click on validate button.
/images/integrations/teamtailor/setup/step-8.png

9. Once validated, click on connect button.
/images/integrations/teamtailor/setup/step-9.png

10. Congratulations! You are now connected to Teamtailor.
/images/integrations/teamtailor/setup/step-10.png
