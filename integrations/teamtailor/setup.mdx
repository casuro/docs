## Connection Guide

Follow these steps to seamlessly integrate Teamtailor with Casuro.

<Steps>
  
  <Step title="Initiate Connection">
    
    Start by navigating to your settings in Casuro.

    <Frame caption="Open Casuro and click on 'Settings' in the left menu bar.">
      <img src="/images/integrations/teamtailor/setup/step-1.png" alt="Settings Menu" />
    </Frame>
    <br/>
    <Frame caption="Under the 'ATS Integrations' tab, locate Teamtailor and click 'Connect'.">
      <img src="/images/integrations/teamtailor/setup/step-2.png" alt="Connect to Teamtailor" />
    </Frame>

  </Step>

  <Step title="Configure Teamtailor Settings">
    
    You will need to retrieve specific keys from your Teamtailor account to complete the form.

    <Frame caption="A configuration form will appear in Casuro requesting an Integration Key and an API Key.">
      <img src="/images/integrations/teamtailor/setup/step-3.png" alt="Configuration Form" />
    </Frame>
    <br/>
    <Frame caption="In a new tab, go to the Teamtailor Marketplace, search for 'Casuro', and ensure it is installed and enabled.">
      <img src="/images/integrations/teamtailor/setup/step-4.png" alt="Teamtailor Marketplace" />
    </Frame>
    <br/>
    <Frame caption="Click on the Casuro integration card and select 'Go to settings'.">
      <img src="/images/integrations/teamtailor/setup/step-5.png" alt="Integration Settings" />
    </Frame>

  </Step>

  <Step title="Authenticate & Activate">
    
    Finalize the setup by validating your credentials.

    <Frame caption="Copy the 'Integration Key' from the Teamtailor settings page and paste it into the Casuro form.">
      <img src="/images/integrations/teamtailor/setup/step-6.png" alt="Copy Integration Key" />
    </Frame>
    <br/>
    <Frame caption="In Teamtailor, navigate to the 'API' section in the sidebar. Create a new API Key with 'Admin' scope (Read/Write) and copy it.">
      <img src="/images/integrations/teamtailor/setup/step-7.png" alt="Create API Key" />
    </Frame>
    <br/>
    <Frame caption="Paste the API Key into the Casuro form and click 'Validate' to verify the connection.">
      <img src="/images/integrations/teamtailor/setup/step-8.png" alt="Validate Keys" />
    </Frame>
    <br/>
    <Frame caption="Once validated, the 'Connect' button will become active. Click it to finish.">
      <img src="/images/integrations/teamtailor/setup/step-9.png" alt="Completing Connection" />
    </Frame>
    
    Congratulations! Your Teamtailor integration is now active.

    <Frame>
      <img src="/images/integrations/teamtailor/setup/step-10.png" alt="Connection Success" />
    </Frame>

  </Step>

</Steps>
